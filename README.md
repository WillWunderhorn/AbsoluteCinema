# Absolute Cinema

Adds 10 tools for creating cinematic footage and a menu to control the game.

**Built-in tutorial included!**

**Features:**

* Fly Mode
* Smooth Camera
* Cinematic Flight
* Zoom
* Look At
* Dutch Angle
* Hide HUD
* Vertigo
* Slow Motion
* Notifications
* Weather Menu
